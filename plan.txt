# Автоматизация проекта

- [ ] Создать проект локально
- [ ] Создать репозиторий
echo "# py_selenium_mini_project" >> README.md
git init
git add README.md
git commit -m "first commit"
git branch -M main
git remote add origin https://github.com/Vasanter/py_selenium_mini_project.git
git push -u origin main

- [ ] Инициализировать репозиторий локально
- [ ] Сгенерировать ci_token в GitHub для отчетов
- [ ] Сделать первый коммит в origin/main
- [ ] Создать ветку gh-pages
- [ ] Убедиться gh-pages инициализированы
- [ ] Построить структуру проекта(папки)
pages - объекты страниц
base - базовые конфигурационные файлы для страниц и тестов
config - ссылки/урлы
tests - для тестов
conftest.py - фикстуры и пр.
.env - для скрытия логина/пароля
установить зависимости: pip install selenium pytest webdriver-manager allure-pytest requests python-dotenv ; pip freeze > requirements.txt
